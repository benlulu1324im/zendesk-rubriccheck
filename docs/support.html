Setup Guide & Support

Get RubricCheck QA running on your Zendesk Support instance in under 3 minutes.

1. Install & Authorize via Zendesk Global OAuth

  1. Install RubricCheck QA from the Zendesk Marketplace.
  2. Click the RubricCheck shield icon in Zendesk's left navigation bar.
  3. Open Billing & Connection, confirm your subdomain, and click Connect Zendesk OAuth.
  4. Approve the minimal granular permissions: tickets:read, tickets:write, webhooks:read, webhooks:write.

2. Automatic Event Webhooks

Once OAuth is approved, RubricCheck QA automatically registers an HMAC-signed Zendesk webhook listening to ticket.attachment_linked_to_comment, ticket.comment_added, ticket.status_changed, and ticket.attachment_redacted_from_comment.

3. Redacting Exposed Screenshots & PDFs

Whenever a screenshot or PDF contains a credit card, passport/ID, SSN, live API key, password, or IBAN, RubricCheck QA tags the ticket rc_pii_exposed and highlights it in the ticket sidebar and Open PII Queue. Clicking Redact attachment calls Zendesk's Comment Redaction API (PUT /api/v2/comment_redactions/{comment_id}) to permanently scrub the file — even on closed tickets.

4. Need Help?

Email support@rubriccheck.app with your Zendesk subdomain. Typical response time: under 1 business day.
