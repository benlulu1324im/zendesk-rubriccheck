Privacy Policy & AI Data Usage Disclosure

Effective Date: November 25, 2026

Core Commitments: (1) Customer Zendesk tickets and attachments are never used to train AI models. (2) Ticket attachments (screenshots, images, and PDFs) and raw message transcripts are processed strictly in transient RAM and are never written to disk, object storage, or our database.

1. Data We Process & Data Minimization

When your Zendesk administrator connects RubricCheck QA via Zendesk Global OAuth 2.0, we request only minimal granular scopes: tickets:read, tickets:write, webhooks:read, and webhooks:write.

  • Transiently processed (RAM-only, immediately discarded): Ticket comment bodies and supported image/PDF attachments fetched for evaluation.
  • Persisted metadata only: Zendesk subdomain, encrypted OAuth tokens (AES-256-GCM), configured QA rubrics, numeric evaluation scores, boolean PII category flags, attachment IDs/filenames (needed to trigger Zendesk Comment Redaction), and Paddle subscription status.

2. AI Processing & Zero Model Training Compliance

RubricCheck QA evaluates tickets using Google's Gemini Decisions API (gemini-decision-1, with fallback to gemini-3.5-flash-lite using store: false) strictly under a Google Paid Tier API agreement. Under Google's Paid Tier API Terms, customer inputs and outputs are never used to train or improve Google AI models, in full compliance with Zendesk's Developer Terms and AI usage rules. Standard Google Paid API abuse-monitoring safeguards apply; RubricCheck QA itself retains zero copies of submitted media or conversation text.

3. Sub-Processors

  • Google LLC (Google Cloud Run & Gemini Paid API): Application hosting and stateless multimodal rubric/PII scoring.
  • Paddle.com Market Limited: Merchant of Record handling subscription billing, payment methods, invoicing, and global VAT/Sales Tax compliance. RubricCheck QA never stores credit card numbers.

4. Security & Encryption

  • All data in transit is encrypted over TLS 1.2+.
  • Zendesk OAuth access tokens, refresh tokens, and webhook signing secrets are encrypted at rest with AES-256-GCM.
  • ZAF iframe requests are authenticated using RS256 signed URL JWTs verified against your Zendesk app public key; inbound Zendesk and Paddle webhooks are verified via HMAC-SHA256 signatures.

5. Retention, Revocation & GDPR Rights

Administrators may revoke Zendesk OAuth access at any time in Zendesk Admin Center. Upon uninstallation or written deletion request to privacy@rubriccheck.app, all tenant records, rubrics, encrypted tokens, and evaluation metadata are permanently erased within 72 hours.
